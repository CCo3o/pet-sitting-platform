# 基于 Spring Boot 和 Vue3 的宠物上门喂养服务平台

主人、喂养员、管理员登录后分别进入宠物照护助手、服务执行助手、平台运营助手，基于 Spring AI 与 DeepSeek 按角色调用业务工具。支持预约草稿、履约记录草稿与投诉处理建议，经人工核实确认后执行。新版演示步骤与验证边界见 [多角色智能工作台](docs/05-role-agent-workspaces.md)。既有主人预约真实 DeepSeek 固定评测9/9通过；新增角色已做本地协议验证，真实模型效果待验收。尚未上传GitHub、尚未部署公网。

## 本地启动与升级

在项目根目录打开两个 PowerShell 终端，分别运行：

```powershell
.\scripts\dev.cmd run
```

```powershell
.\scripts\frontend.cmd dev
```

访问 http://127.0.0.1:5173 。后端为 http://127.0.0.1:8080 。已有服务需先在原终端按 Ctrl+C，再启动最新代码。前端已经开启时会自动刷新；后端必须重启才能应用接口与 Flyway 数据库迁移。

`.cmd` 入口只在启动的 PowerShell 子进程允许执行项目脚本，不改变系统执行策略。当前 Java 21 和 Maven 在 `.tools/`，其他机器可自行安装。首次前端启动前可在 `frontend/` 运行 `npm ci`。

## 已实现功能

| 角色 | 功能 |
| --- | --- |
| 主人 | 注册登录；宠物类型、品种、年龄、注意事项管理；地址和联系人管理；按日期、预算筛选时段；查看喂养员介绍与评分；预约、模拟支付、取消；查看服务记录和私有照片；验收、评价、投诉；预约助手 |
| 喂养员 | 注册登录；提交/修改资料并等待审核；设置报价；发布和撤下时段；接单/拒单；开始服务；上传照片与记录；提交完成；查看订单与投诉反馈 |
| 管理员 | 用户列表与启用/停用；喂养员审核；维护一个日常喂养服务包；查看所有订单和真实统计；处理投诉；查看 Agent 调用、失败、草稿、耗时与最终响应 Token 统计，以及逐工具参数和结果摘要 |

订单状态：待接单 → 已接单 → 服务中 → 待主人确认 → 已完成；待接单/已接单可在开始前取消，待接单可拒绝。待接单超过两小时或到达预约开始时间后，会由每分钟定时任务关闭。取消、拒单、超时释放时段；已支付的关闭订单标记模拟退款。

服务时长为 30 分钟至 4 小时；喂养员需要为路途预留空隙。实际服务开始和结束时间由后端校验，页面没有跳过真实时间的按钮。履约完整流程的自动化测试在测试库中推进时间，不改动开发订单。

## 技术栈

- Java 21、Spring Boot 3.5.16、Spring Security、BCrypt、JWT + 数据库会话撤销。
- Vue3、TypeScript、Vite、Element Plus、Vue Router、Pinia，业务页面和较大组件按需加载。
- MyBatis 管理宠物、地址和喂养员资料；JdbcTemplate 明确实现订单事务与行锁 SQL。
- MySQL 8.4、Flyway 版本迁移；保留 H2 快速开发与内存测试。当前默认开发库仍为 `data/pets`，生产使用 MySQL。
- Spring AI 1.1.8 原生 DeepSeek 模型接入、四个受限工具、多轮对话、预约草稿与用户确认。
- JUnit、MockMvc、H2/MySQL 集成测试、Playwright 浏览器测试，准备了 Docker Compose 与 GitHub CI。

## 正确性与权限

预约在同一事务中锁定主人账户、宠物/地址、喂养员账户和时段；统一锁顺序保护资料、审核状态、报价和占用。数据库唯一约束保护 `(owner_id,request_key)`，同键相同请求返回原订单，同键不同参数返回 409。取消状态更新、时段释放和模拟退款原子提交；重复取消不会释放后来订单占用的时段。

宠物、地址、服务内容和价格保存订单快照。删除资料采用软删除，保留历史订单。照片检查实际 PNG/JPEG 格式、最大5MB、最长边4000像素，重新编码并使用服务端生成文件名；只允许指定喂养员上传，订单双方与管理员查看，照片响应按文件流返回。密码和登录凭证不放进业务列表。

JWT 两小时过期，默认随机密钥在重启后变化，开发环境重启须重新登录。生产要求持久密钥。停用用户撤销全部会话，重新启用仍需重新登录。注册不能获取管理员角色，管理员不能停用自己；后端独立检查权限，前端路由仅改善交互。

## DeepSeek 配置

在项目根目录终端执行一条命令，按提示输入密钥并自动启动后端：

```powershell
.\scripts\start-agent.cmd
```

输入会隐藏；密钥只传入本次进程，不写入文件。不要发到聊天或提交仓库。旧后端需先按 Ctrl+C 退出。

可选配置 `DEEPSEEK_MODEL`（默认 deepseek-chat）和 `DEEPSEEK_BASE_URL`（默认 https://api.deepseek.com）。未配置时助手会显示不可用，普通预约正常使用。

工具限定为当前用户的宠物、地址区域、时段报价查询和草稿生成。模型不能提供 actor，也没有创建订单/付款工具。主人点击确认后，后端重新校验草稿归属、15分钟有效期、资料/服务内容变化、报价和时段占用，再幂等创建订单。草稿不占用时段，抢占失败会返回明确错误。

单次最多六轮工具执行，模型响应长度和连接超时受限；每会话20轮对话，按北京时间每日配额限制每用户50次助手调用，配额在事务中预留，避免并发超额，并提供对话租约与失败观测。身份认证接口和助手接口还具备单实例 IP 限速。模型输出作为文本显示，不作为 HTML 执行。

已用本地模拟 DeepSeek HTTP 服务验证 Spring AI 工具协议、补问、多轮历史、未知写工具拒绝、调用循环上限和供应商故障恢复；已通过真实DeepSeek接口跑通补问、查询、草稿、确认创建订单，最终9个固定评测用例全部通过，共15条模型消息、45次实际工具执行；[评测报告](docs/evaluation/latest-real-evaluation.md)与模拟协议测试分开保存，不把本轮用例通过率当作生产成功率。当前 Token 统计仅包含最终响应；中间工具轮次费用需与供应商账单核对。

```powershell
$env:MYSQL_TEST_URL='jdbc:mysql://127.0.0.1:3306/pets_test?connectionTimeZone=UTC&forceConnectionTimeZoneToSession=true'
$env:MYSQL_TEST_USERNAME='测试库用户'
$env:MYSQL_TEST_PASSWORD='测试库密码'
.\scripts\dev.cmd test
```

测试库会写入合成数据，只能使用独立测试库。H2单元测试使用内存库。浏览器测试使用独立8081后端、5181前端和独立内存数据库；没有关闭你原来的8080/5173服务。旧版H2数据库保留账号与订单的迁移测试已通过。

## 当前边界

支付与退款为模拟；没有实际扣款。预约不要求主人与喂养员区域相同；主人保留完整上门地址，喂养员根据地址和报价决定接单或拒单。未接地图测距。喂养员审核为管理员审阅填写资料，没有外部身份核验。暂不包含短信、忘记密码、即时聊天、真实支付、GPS签到和医疗服务。图片保存在本地文件卷，多实例部署需迁移对象存储；限速和 Agent 模型调用观测也需按部署规模扩展。
